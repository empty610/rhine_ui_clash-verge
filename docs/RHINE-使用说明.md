# Clash Verge Rhine

这是基于 Clash Verge Rev 2.5.9 源码制作的 Windows x64 桌面客户端。新版采用暖灰、米白、琥珀色和档案编号的平面设计，视觉参考 RhineLabUI。它是独立的本地定制版。

## 使用

1. 保持整个文件夹完整，双击 `启动 Rhine.cmd` 或 `clash-verge.exe`。
2. 在「订阅」页导入自己的订阅链接或本地 Clash 配置，选择配置后到「代理」页选择节点。
3. 按需开启系统代理；TUN 需要相应权限或服务支持，首次使用可能提示安装或更新服务。

运行成品不需要 Node、Rust 或编译工具，电脑只需具备 WebView2。当前电脑已经安装 WebView2。请勿只复制主 EXE：同目录的两个 Mihomo 内核和 `resources` 文件夹也是程序的一部分。

正常使用前请退出其他 Clash 客户端，避免争用系统代理或特权服务。当前正在使用的原版没有被关闭；本次验证使用隔离预览和独立端口。

## 安全查看界面

双击 `隔离预览.cmd` 可在保留原版连接时查看新版桌面界面。窗口标题含 `UI PREVIEW`，系统代理与 TUN 操作被锁定。此模式不启动内核，不用于代理上网；正式使用请退出预览后启动正常程序。

正常配置目录：`%APPDATA%\io.github.clash-verge-rhine.desktop`。

预览配置目录：`%APPDATA%\io.github.clash-verge-rhine.preview`。

原版配置不会自动迁移。没有附带任何付费订阅、真实代理节点或账号凭据。

## 内存与外观

保留 Tauri + Rust + Mihomo 桌面架构，使用系统字体和小型 SVG，不增加 3D 场景或动画背景。页面按需加载，首页 IP 检测、测速等附加面板默认关闭，可在首页右上角设置中开启。关闭到托盘后默认两分钟进入轻量模式、释放界面；代理内核继续运行。

亮色为默认主题，也支持暗色主题。实际内存受 WebView2、订阅节点数、规则数量、连接数量和启用功能影响，不能以空配置测试结果代表所有使用场景。

切换页面时，右侧内容以约 200 毫秒的淡出淡入过渡，侧栏保持稳定。开启系统的“减少动态效果”偏好时，页面直接切换。

侧栏标志使用固定比例的 SVG，展开与折叠侧栏时均保持对齐。首页网络图参考提供的视频重绘为 32 秒的平面循环：闭合轮廓连续变形，外圈平滑呼吸；航天器头部亮点逐渐成为轨道中心，尾焰消退时圆环沿同一运动中心扩散，随后行星与卫星进入。返回时原有圆环直接变形成闭合轮廓。保留底部四色弧段，并补全原视频被数字遮挡的线条。图形中不含数字、音频、视频、模糊滤镜或位图纹理。窗口失焦、隐藏或图形滚出视野时暂停；开启“减少动态效果”时静止。动画使用 CSS，无逐帧 JavaScript、图片序列或额外动画库。本轮优先调整观感，尚未重新测量客户端的内存占用。

为保留定制界面，官方应用自动更新已关闭；内核更新功能仍保留。界面源码位于同级 `clash-verge-rhine` 文件夹，重编译方法见 `RHINE-EDITION.md`。

## 原版 Rhine 本机验证记录（2026-10-16）

Windows x64 release 编译、前端类型检查、Lint 和架构检查已通过。打包后的 EXE 已实际启动，首页界面结构正常加载，隔离预览中的系统代理与 TUN 控件已锁定。桌面截图接口超时，未完成所有页面的视觉和交互验收。

随包 Mihomo v1.19.32 使用独立端口、空白测试配置完成 HTTPS 请求，返回 HTTP 200。测试前后原版客户端、内核和服务进程仍在运行，系统代理设置一致。未导入真实订阅，也未启用 TUN 或切换原版服务。

单次空配置采样：独立内核工作集约 24.3 MiB；新版首页预览含 WebView2 共 7 个进程，私有内存合计约 204.7 MiB、工作集合计约 443.9 MiB（含共享页，不能当作独占物理内存）。此采样不包含代理内核，也不是长期运行的内存上限。轻量模式释放窗口后的常驻占用尚未实测。
